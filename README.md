# my chuanshi skill

为四川师范大学微信公众号撰写、修改推文策划案的 Codex Skill。

## 使用方式

将本仓库下载并解压，把包含 `SKILL.md`、`agents/` 和 `references/` 的目录命名为 `my-chuanshi-skill`，放入 Codex 的个人技能目录 `~/.codex/skills/`。下一轮对话输入：

```text
使用 $my-chuanshi-skill
```

技能会先询问是写新的策划案，还是修改现有策划案。选择修改后，等待提供原稿及修改要求，再有针对性地修改。

## 主要规则

- 每篇策划案不超过300字，默认校内取材，拍摄和制图安排应切实可行。
- 联网核实近期活动、景观和实际日期，来源不限官网，不编造、不把旧闻当近况。
- 策划案可附图也可不附图，图片数量不限；附图及参考图须真实、实际查看且来源可追溯。
- 不使用“早八”等禁用表达，不提出“拍声音”等抽象摄影任务。
- 不懂或不确定的用户要求先询问，不擅自决定。
- Word 全文宋体：标题三号加粗，署名“策划|曹瀚元”小四加粗，正文小四，重要执行要求局部加粗。

完整规则见 [SKILL.md](SKILL.md)。案例、事实核验、图片使用与 Word 排版说明保存在 [references/](references/) 中。
